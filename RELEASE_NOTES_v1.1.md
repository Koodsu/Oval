# Oval 1.1

**A whole new look, and a name to match.**

- Introducing Oval (formerly Bridge) — new name, new logo, and a full redesign with a bolder, cleaner look, including dark mode.
- Suggest new activities for Oval — submit ideas and we'll add the ones that fit.

- Fixed copy/paste issues in messaging and profile fields.
- General bug fixes and performance improvements.
