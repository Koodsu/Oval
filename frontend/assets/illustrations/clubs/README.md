# Club illustration provenance

These production assets were created with the built-in ImageGen workflow for
the July 2026 club-experience rebuild. Shared direction: warm cream and Oval
scarlet editorial palette, diverse college students, realistic campus
belonging, generous mobile-safe negative space, and no logos, text, brands, or
watermarks.

| Asset | Prompt intent |
| --- | --- |
| `chat-empty.png` | Two students beginning a friendly club conversation |
| `private-space.png` | Calm, reassuring private leadership space |
| `events-empty.png` | Students preparing the first club gathering |
| `applications-empty.png` | Welcoming application and review scene |
| `delete-club.png` | Careful archival/destructive-action metaphor |
| `recovery.png` | Supportive reconnection and retry scene |
| `member-search-empty.png` | Friendly roster search with no matching person |

The Photography Club cover is stored separately at
`../../content/clubs/photography-club-hero.png`. Its prompt requested a premium
16:9 golden-hour campus photograph of three diverse students reviewing a
mirrorless-camera image together, with subtle cream/scarlet styling and quiet
space for native overlay text and controls.
