# Activity catalog artwork

These 41 square illustrations were generated as new assets with the image-generation tool, using the existing `basketball.jpg`, `study-session.jpg`, `cafe-hangout.jpg`, and `gaming.jpg` files as style references. They were exported as 1024×1024 JPEGs at quality 82.

Shared prompt direction:

> Square activity-card illustration for the Oval college social app. Match the reference images' established warm, softly painterly editorial digital-illustration style, cohesive palette, gentle natural light, and friendly expressive college-age characters age 18+. Make the activity instantly readable at small thumbnail size with a balanced close-to-medium composition and clear faces and hands. No text, letters, logos, school branding, watermark, border, UI, or photographic realism. Avoid duplicated people, malformed hands, and background clutter.

Each image used a separate generation call with an activity-specific scene appended to that direction—for example, a campus-library collaboration for `study-group`, a friendly table card game for `card-games`, food packing for `food-bank-volunteering`, and an ensemble practice-room jam for `play-practice-music`.

The filenames are stable backend `artworkKey` values. Display-title changes should not rename these files or keys.
