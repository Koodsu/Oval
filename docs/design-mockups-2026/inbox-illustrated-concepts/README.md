# Illustrated Inbox redesign concepts

Eight visual concepts for Oval's Inbox, with populated and empty states for
All, Messages, Pod chats, and Invites.

## Shared art direction

- Editorial hand-drawn student characters
- Fine ink outlines with soft watercolor/cel shading
- Light paper texture and gentle fades into the interface
- Warm white canvas, Oval scarlet, muted violet, peach, pale blue, and charcoal
- Crisp rounded native UI that remains practical to build in React Native
- No photography or photorealistic rendering
- No university names, initials, logos, mascots, branded apparel, athletic
  marks, school-specific insignia, or recognizable campus landmarks

## Concepts

1. `01-all-full.png` — full cross-channel activity overview
2. `02-all-empty.png` — illustrated Inbox introduction and next steps
3. `03-messages-full.png` — recent people, priority thread, conversation list
4. `04-messages-empty.png` — people discovery and conversation starters
5. `05-pod-chats-full.png` — featured group chat and active pod conversations
6. `06-pod-chats-empty.png` — pod discovery and suggested plan types
7. `07-invites-full.png` — pod invites, friend requests, and sent requests
8. `08-invites-empty.png` — caught-up state, invite education, and sharing
