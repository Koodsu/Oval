## Design intent

- Scarlet is reserved for active controls, high-value actions, and clear state.
- Main content uses solid warm surfaces; blur is limited to navigation chrome.
- Empty states remain useful and emotionally warm, with a next action on every screen.
- Officer tools feel trustworthy and understandable rather than like enterprise admin software.
- Community photography and illustration center diverse students collaborating in realistic campus moments.
- Destructive and private states use calm, explicit language and safe action hierarchy.

These are high-fidelity visual concepts rather than pixel-exact screenshots of the current implementation. Product copy, permissions, and control visibility should still be validated against the corresponding React Native screen before implementation.
