Clubs screen — three directions

The current ClubsHomeScreen reads as a utility list: every club is a 42 px mark, a name, one administrative caption, and a chevron, behind a search bar, a segmented control, and a category chip row. Nothing a club has actually done appears anywhere, and Discover is sorted by memberCount descending — a static ranking, so the screen looks identical every time it opens. These three directions each change the unit of content, not the styling.

Unit = a thing a club did. Clubs become authors, not rows. Chronological, mixed.
